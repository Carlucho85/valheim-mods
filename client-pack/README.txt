AKAI HOSHI: CHANGARÖK — PAQUETE DE MODS PARA CLIENTE

Instalación con un clic:
1. Ejecuta AkaiHoshiLauncher.exe.
2. Selecciona la carpeta de Valheim si no se detecta automáticamente.
3. Pulsa «Instalar / actualizar mods» y después «Jugar».

El launcher instala BepInEx si falta, descarga el pack de cliente vigente desde
GitHub y verifica su SHA-256 antes de modificar el juego. Los archivos
reemplazados por primera vez se guardan en una copia de seguridad local.

No distribuyas este archivo manualmente si utilizas el launcher: este README se
incluye también dentro del paquete para identificarlo.
